How to Route Your Entire Home Wi-Fi Through J.A.R.V.I.S.

Clone this repository on any machine or Raspberry Pi on your home Wi-Fi to run the local RFC 1035 DNS Sinkhole & Packet Collector:

STEP 1: Launch NetPulse Gateway on Your Home Machine GATEWAY HOST 
git clone https://github.com/clvncx1-web/netpulse.git
cd netpulse && sudo python3 server.py --port 8080 --dns-port 53
STEP 2: Point Your Router's DHCP DNS to Your Host IP WHOLE-HOME COVERAGE

Open your home router settings (192.168.1.1) → DHCP / LAN Settings → set Primary DNS Server to the local IP of the computer or Raspberry Pi running NetPulse.

OPTIONAL STEP 3: Test Live UDP DNS Sinkhole via CLI VERIFIED 
dig @127.0.0.1 -p 5354 ads.roku.com A
# Returns 0.0.0.0 (SINKHOLED) in 0.1 ms
